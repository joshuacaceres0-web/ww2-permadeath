VANGUARD '44 — Original 16-bit 1940s music samples
=====================================================
All 4 tracks are ORIGINAL compositions written for this game.
No copyrighted 1940s songs, melodies, or samples were used.
No Glenn Miller, no Andrews Sisters, no existing tunes, and
Battle Drums is NOT the Battlefield 1942 theme — it is an original
track in the same feel/style only (driving war drums, heroic
brass-like fanfare, minor key, march tempo), inspired by, not a
copy of, Battlefield 1942.
Composed in Python (stdlib wave + math only), square/triangle waves,
22050 Hz, 16-bit mono PCM WAV. Each is 16 bars, loopable (ends on tonic,
total beats = 64), under 60 seconds.

Files (in frontend/public/music/):
- march-to-normandy.wav
- swing-in-the-barracks.wav
- letters-home.wav
- battle-drums.wav

How to use in the game:
- Play as audio files from /music/<name>.wav, loop=true, or
- Port the note sequences below to WebAudio in frontend/src/game/sfx.ts
  (square = lead, triangle = bass/lead, sine = pads, noise = snare/hat).
  Note format below: Note:Beats, R = rest. Bar lines | separate bars.

V4 — REAL INSTRUMENTS (2026-11-10, rebuilt from scratch)
All 4 tracks overwritten as v4, same names / roles / BPM / keys /
melodies / chords as v3 (note sequences in sections 1-4 above are
unchanged), but with realistic instrument synthesis instead of
chiptune-style waves. No square-wave leads anywhere.
- Format: 44100 Hz, STEREO, 16-bit PCM (pcm_s16le), 16 bars / 64 beats,
  loopable, under 60 s. Stereo width: leads panned slightly off-centre,
  pads spread wide (L -0.55 / centre / R +0.55), drums and bass centred.
- Strings: 3 detuned sine-stack voices (+5/-5 cents chorus detune) +
  2nd harmonic, slow attack (0.18-0.8 s), 5.5 Hz vibrato ramping in,
  release tails — used for pads and the Letters Home lead.
- Brass: FM synthesis, carrier + modulator at 1:1 ratio, modulation
  index 4.5 decaying to 2.2 (breath-like swell), slow attack,
  detuned second carrier for section chorus — fanfare leads in
  March and Battle Drums, stabs in Swing.
- Piano / keys: Karplus-Strong plucked-string synthesis (noise-excited
  delay line, 0.9962 decay) + sine body with exponential decay —
  Swing lead + harmony, Letters Home chord arpeggios.
- Bass: sine + 2nd harmonic, fast attack, exponential pluck decay.
- Drums: kick = sine 150->45 Hz pitch drop + click transient + low
  thump; snare = high-passed noise burst + 190 Hz body tone;
  hats/cymbals = high-passed (differentiated) noise with decay;
  toms/timpani = sine pitch drop with long decay.
- Dynamics: downbeats louder than passing notes, per-event velocity,
  attack/release envelopes on every voice — no flat chiptune volume.
- Reverb: circular multi-tap stereo echo (0.13 s @ 16%, 0.27 s @ 9%,
  0.41 s @ 5%) — taps wrap around the loop point so the tail feeds
  bar 1 and the loop stays seamless.
- Generator: /tmp/gen_music_v4.py (Python stdlib only: wave, math,
  audioop for C-speed mixing; no external libs, no samples, no
  copyrighted songs). v3 files backed up to /tmp/music-v3-backup/.
- One correction vs v2/v3 notes: the Gm chord is G-Bb-D (the old
  notes listed G-B-D); v4 uses Bb, as a minor triad requires.
